# Disclaimer and deployment boundary

This repository is a technical design and unaudited prototype. It does not determine whether a formula, proof, manuscript, dataset, codebase, patent claim, token, revenue share, grant, bounty, license, or vault interest is legally protectable or regulated in any jurisdiction.

A mathematical fact cannot be made true or exclusively owned by minting a token. Copyright, patent, contract, employment, university, grant, export-control, sanctions, privacy, tax, securities, commodities, money-transmission, consumer-protection, and research-integrity rules may independently apply.

The recommended V1 Research Credit is a fully backed, closed-loop service credit with restricted transfer. A freely transferable token marketed around a researcher's future profits is a different economic instrument and must be implemented only through an independently designed and reviewed legal wrapper.

The Solidity contracts are reference code only. The ASTRA adapter sends data to a configured API provider; users must classify confidential, regulated, unpublished, export-controlled, personal, or third-party data before transmission. The Lean build runner must be replaced with hardened sandbox infrastructure before accepting hostile artifacts.
