# XLIP-011 — Optional token projections

Tokenization is optional and MUST remain a projection over immutable protocol records.

- Origin certificates SHOULD be non-transferable.
- Proof capsule handles SHOULD be non-transferable by default.
- License, access, and support editions MAY use ERC-1155 where a rights manifest defines the entitlement.
- Transfer of a token MUST NOT rewrite originator attribution or formal status.
- Metadata MUST bind immutable ClaimID/ProofID/ArtifactID and rights-manifest roots.
- A token MUST NOT claim exclusive ownership of mathematical truth.
- A formal dependency token MUST NOT imply that downstream users owe a royalty.
- An Open Commons capsule token MUST NOT conceal mandatory per-use fees.

A public transferable instrument linked to future research profit is outside the core service-credit specification and requires a separate legal and technical wrapper.
